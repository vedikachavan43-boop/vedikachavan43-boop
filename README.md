# 🥗 NutriAI – AI Powered Food Calorie & Diet Recommendation System

## 📌 Overview

NutriAI is an AI-powered web application that detects food items from an uploaded image, estimates nutritional information, and provides personalized calorie analysis and diet recommendations.

The project combines Artificial Intelligence, Computer Vision, and Web Development to help users make healthier food choices.

---

## ✨ Features

- 🍎 Food image upload
- 🤖 AI-based food detection using YOLOv8
- 📊 Calorie estimation
- 🥗 Nutrition information
- 💡 Personalized diet recommendations
- 👤 User Registration & Login
- 📱 Responsive and user-friendly interface

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/NutriAI.git
```

### Move to project folder

```bash
cd NutriAI
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```

## 📷 How It Works

1. Upload a food image.
2. AI model detects the food item.
3. The system estimates calories and nutrition values.
4. Personalized diet suggestions are displayed.
